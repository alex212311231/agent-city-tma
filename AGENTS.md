# Agent City

Статические файлы обслуживаются GitHub Pages, а локальная копия и статусы доступны на порту 8765. Сохраняй подписанный вход Telegram Mini App, реальные статусы и работу лифта. В веб-сцене есть только пять именованных персонажей, по одному на роль. Фоновые сборы MOEX и грантов отображаются в статусах.

Для проверки города и после существенных изменений сцены, материалов, маршрутов или управления используй одного агента city_quality из .codex/agents/. Он запускает tests/city-audit.mjs, осматривает снимки и исправляет воспроизводимые дефекты в пределах проекта. Команды запуска указаны в tests/README.md.
